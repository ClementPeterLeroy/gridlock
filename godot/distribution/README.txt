GRIDLOCK v3.0-beta.2 - The Final Countdown

Run Gridlock.exe. Keep Gridlock.pck and every companion file beside it.
Godot, Python and the source project are not needed to play the exported game.
Windows x86-64 with a graphics driver supporting Godot's Forward+ renderer is required.

The official intro plays once. Select Versus for two local human players, or use
Battle Royale, Blitz or Rise of the Machines for AI configuration. How to Play
explains movement, jumping, walls and timing. Escape pauses or returns.

Settings includes volumes, animations, camera, display mode, resolution, UI scale
and VSync. Display mode/resolution changes must be confirmed within ten seconds;
otherwise the previous configuration returns. Minimum supported window: 1280x720.
On smaller desktops a safe window is fitted; this is outside official UI support.

Local preferences and diagnostic logs are stored under Godot's Gridlock user-data
folder (%APPDATA%/Godot/app_userdata/Gridlock on standard Windows installations).
There is no telemetry. Audio is development placeholder material.
